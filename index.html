"확인되지 않은 개발자" 경고가 발생하나요?

Magic Note는 개인 개발 프로젝트로 제작된 Swift 앱으로, 현재 Apple 공식 개발자 유료 인증서 등록이 되어있지 않은 상태입니다.

따라서 macOS의 기본 보안 시스템인 Gatekeeper(게이트키퍼)에 의해 "확인되지 않은 개발자가 배포했기 때문에 열 수 없습니다" 또는 "악성 소프트웨어가 있는지 확인할 수 없습니다"라는 알림이 뜰 수 있습니다. 앱 내부에는 어떠한 유해 코드도 포함되어 있지 않으므로 아래 3가지 방법 중 하나를 통해 안전하게 해제 후 실행하실 수 있습니다.

간단한 실행 방법 (3가지 중 선택)

방법 1 (가장 추천) 3초 완료

마우스 우클릭 후 열기

  1. 다운로드한 Magic Note 앱을 응용 프로그램 폴더로 이동합니다.
  2. 앱 아이콘에서 마우스 우클릭 (또는 Control + 클릭)을 합니다.
  3. 메뉴에서 [열기(Open)]를 클릭합니다.
  4. 보안 확인 창이 뜨면 [열기] 버튼을 다시 누르면 정상 실행됩니다.
최초 1회만 실행하면 이후에는 더블클릭으로 바로 열립니다.
방법 2 설정 앱 이용

시스템 설정에서 허용

  1. Mac의 [시스템 설정 (System Settings)]을 엽니다.
  2. 좌측 사이드바에서 [개인정보 보호 및 보안]을 선택합니다.
  3. 아래로 스크롤하여 [보안] 섹션을 확인합니다.
  4. "Magic Note의 사용이 차단되었습니다" 문구 옆의 [확인 없이 열기(Open Anyway)] 버튼을 클릭합니다.
macOS 공식 보안 허용 절차입니다.
방법 3 고급 사용자

터미널 명령어로 해제

다운로드된 파일의 격리 플래그(Quarantine Attribute)를 제거하여 게이트키퍼 경고 없이 바로 실행합니다.

xattr -cr /Applications/MagicNote.app

자주 묻는 질문 (FAQ)

궁금한 점이 있으신가요?

다운로드 후 어떻게 설치하나요?

다운로드받은 압축 파일 또는 .app 파일을 Mac의 /Applications (응용 프로그램) 폴더로 드래그하여 옮겨주시면 설치가 완료됩니다.

앱을 실행할 때마다 게이트키퍼 해제를 반복해야 하나요?

아닙니다. 최초 1회만 [우클릭 → 열기] 또는 [확인 없이 열기]를 통해 실행을 승인하시면, 이후에는 앱 아이콘을 더블클릭하기만 해도 일반 앱처럼 바로 실행됩니다.

Apple Silicon(M1/M2/M3/M4)과 Intel 맥 모두 지원하나요?

네, 모든 최신 Apple Silicon 맥 및 Intel 기반 Mac에서 원활하게 동작합니다. (macOS Monterey 12.0 이상 권장)
